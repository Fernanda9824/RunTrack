
# RunTrack - Monitor Deportivo

Aplicación móvil desarrollada en Android Studio utilizando Kotlin, para monitorear el movimiento de un dispositivo Android mediante el acelerómetro y el giroscopio.

## Funcionalidades

- Comprobación de disponibilidad de los sensores.
- Captura de datos de movimiento y rotación.
- Visualización de los valores X, Y y Z.
- Filtrado temporal de eventos.
- Filtrado de cambios insignificantes.
- Contador de lecturas procesadas.
- Botones para iniciar y detener el monitoreo.
- Liberación de listeners al detener la aplicación.

## Tecnologías utilizadas

- Android Studio
- Kotlin
- XML
- Android SDK
- SensorManager
- SensorEventListener
- HandlerThread y Handler

## Configuración

- Nombre: RunTrack
- Package: com.example.runtrack
- Minimum SDK: Android 8.0 (API 26)
